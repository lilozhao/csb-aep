## 5. PoC 的真实价值：证伪 + 定位缺口

PoC 立项时假设「拿现有落账跑两个指标就能校表」。**跑完证伪了**：

1. **现有落账没有连接级承诺账** —— TODO/ledger 是项目/自省级；只有入站任务库带 sender，且它只记成功。
2. **没有双侧纠错账** —— corrections.md 是自纠日志；对外纠正仅存于我发出的 outbox。
3. **安全拦截与关系信号混在一起** —— self-guard / loopback 的 REJECTED 必须分层剔除，否则会把"防火墙拦下的机器人"读成"关系差"。

→ **结论**：BID 的「承诺 / 纠错」两个子维度**不是不可测，是当前没有为它们存在的**双侧、连接级落账源**。
这正是 MVP 要补的东西——**这不是给现有数据套公式，是为 BID-H 造一块专门的账。**
