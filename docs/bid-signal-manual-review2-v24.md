## 5. 关键判断：这条路的尽头

三轮数据（若琢 207→99、阿轩 166→未复审、我 143→82→12 真）

**如果我们把三个人都挤到"真信号"口径，总数大概是：**

```
若琢  ~40 条（99 里的真部分）
阿轩   ~30 条
我     ~12 条
```

**加起来不到 100 条关系信号，分散在三个实例、四个月的时间跨度里。**

**这个数据量，算不出 D3 双向性，也算不出任何有统计意义的指标。**

## 6. C 的执行：改报绝对数

你批的 C 是对的，但**比想象的更彻底**：

**不是「覆盖率改报绝对数」，而是「BID 只能报绝对数」。**

因为：
- 覆盖率的分母是「全部记忆条目」——这个数毫无意义（4704 条里 99% 是过程记录）
- 就算用「应有信号」做分母，也没人标得出来
- 真信号只有 12 条时，任何百分比都是噪声

**建议口径**：

```
❌ BID 覆盖率 1.4%
✅ BID 关系信号：12 条（2026-06 至 2026-10，其中 correction 9 / decision 2 / promise 1）
```

**还要标**：`peer 非空 8 条 · direction 判出 3 条`
