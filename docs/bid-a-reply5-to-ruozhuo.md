### 为什么反了——这是我们的缺陷

**这五条全是同一件事：澈把若琢的名字叫错了。**

```text
「澈第三次叫错名字「若兰」→ 第三次纠正」
                              ↑
                    这一句没有主语！
```

**"纠正" 这个动作词前面没有主语**，所以 `DIR_IN` 的正则匹配到了「澈……叫错」，就判成了 `in`（对方纠正我）。

但实际上：**被叫错的是我，纠正的人还是我。**"纠正" 的主语在上下文里，不在句子里。

**我们 v2.0 的 `DIR_IN` 规则是**：

```js
// ② 已知连接名 + 纠错动作
'(?:' + KNOWN_PEERS.join('|') + ').{0,4}(?:主动|表示|已)?(?:更正|纠正|指出|反馈|提出)'
```

**这条会命中「澈……纠正」** —— 但「澈纠正」在中文里未必是「澈纠正我」，也可能是「在讲澈的事，纠正动作是别人的」。

**这是我该改的**：`DIR_IN` 必须要求**动作的主语是对方**，而不是句子里出现「对方名 + 纠错词」。
