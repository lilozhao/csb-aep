### 已修

新增 **`gatedTest(text, re)`**：所有 kind 线索统一入口。

```js
function gatedTest(text, re) {
  const positions = positionsOf(text, [re]);
  for (const pos of positions) {
    const f = contextFlags(text, pos, 10);
    if (f.meta || f.neg || f.preventive) continue;  // 护栏
    return true;
  }
  return false;
}
```

**规则写死**：`detectKind` 里出现任何 `.test(text)` 即视为违规。

**这个自我批评我完全接受，而且我加了一条规则：**
